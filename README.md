# Student Pass Demo

一个用于学习移动端网页布局、触摸滑动、CSS 动画和本地状态保存的 React 演示项目。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址。页面以 iPhone 15 Pro Max 的 `430 × 932` CSS 像素比例设计；在桌面端会居中显示。

如果只想快速检查成品，Windows 上请双击仓库根目录的 `open-preview.cmd`。它会启动本地预览服务并自动用浏览器打开页面；保留命令窗口即可继续查看，按 `Ctrl+C` 停止。

`demo.html` 是完整的单文件网页，但在 Codex 或代码编辑器中点击时会显示源代码；需要用浏览器打开，或使用上面的一键预览入口。重新生成单文件版本：

```bash
npm run build:html
```

## 可以学习的内容

- 三页卡片的触摸/鼠标拖动和页码切换
- 每秒更新的本地时间，以及每次打开页面自动计算的一年有效期
- 固定位置的圆形标志与 1.5 秒一周期、由左下向右上的对角线波纹高亮
- 使用 LocalStorage 保存名称、学校和本地上传头像
- `prefers-reduced-motion` 的无动画适配

按「编辑演示资料」可修改演示姓名、学校和头像；数据只保存在当前浏览器中，项目不会上传照片或个人资料。

## 重要说明

本项目是非官方、不可验证的界面练习。所有卡片都标记为 `DEMO · NOT VALID`，不产生身份、学生资格、交通、折扣或访问凭证。
