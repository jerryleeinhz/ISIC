# ISIC Student Card UI

一个用于学习移动端网页布局、触摸滑动、CSS 动画和本地状态保存的 React 项目。

## 快速检查

Windows 上双击仓库根目录的 `open-preview.cmd`。脚本会启动本地预览并自动用浏览器打开页面；保留命令窗口即可继续查看，按 `Ctrl+C` 停止。

`demo.html` 是完整的单文件网页。不要在代码编辑器里预览它；请直接用浏览器打开，或使用上面的一键预览入口。

重新生成单文件版本：

```bash
npm run build:html
```

## 开发运行

```bash
npm install
npm run dev
```

页面以 iPhone 15 Pro Max 的 `430 × 932` CSS 像素画布设计，在桌面端会按可用空间等比缩放并居中显示。

## 可以学习的内容

- 三页卡面的触摸、鼠标拖动和分页切换
- 每秒更新的本地时间，以及每次打开页面后自动计算的一年有效期
- 固定交错点阵中的 `ISIC` 圆形标记，以及 1.5 秒一周期、从左下向右上的闪动相位
- 第二、三页完整横版卡面旋转 90° 的布局方法
- 点击头像上传图片，并使用 LocalStorage 保存姓名、学校、头像、全部 `ISIC` 标识文字、图 2 姓名字重和二维码网址
- 使用 `qrcode` 生成真实可扫描的二维码；默认目标为本项目 GitHub 仓库，发布后可在编辑器里换成正式页面网址
- 第三页使用 SVG `textPath` 绘制同心圆文字底纹
- `prefers-reduced-motion` 的无动画适配

## 说明

本项目是非官方的界面练习。合作标志、卡号、站点和品牌均为虚构元素；二维码仅打开配置的网址，不产生身份、学生资格、交通、折扣或访问权限。
